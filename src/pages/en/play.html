    How it works

    • It is the real engine, not a cut-down version. Optiline is compiled to WebAssembly with SIMD128 and uses the same neural network as the native release. It runs in a single-threaded Web Worker so the page never freezes.
    • A little slower than native. In the browser it runs about 1.6 times slower than with AVX2. In 100 ms games that gap costs about 40 Elo, measured over 1,600 games with the same time handicap.
    • The ~3100 Elo is the native engine’s at 100 ms per move. Levels 1 and 2 cap the nodes it may search; they are not calibrated to any Elo, so I do not give them one.
    • It downloads about 1.9 MB once (engine and network together), which then stay in the browser cache. The current game is saved in your browser in case you close the tab.
    • Open source. Optiline is GPL-3.0: source code. This build starts from commit 9cec21b with two small patches (SIMD128 kernels and thread-free search), and the script that reproduces it lives in this site’s repository. More in the case study.
